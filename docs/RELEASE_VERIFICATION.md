## 배포 중 발견·수정

AAPT가 gzip 언어파일을 풀어 APK에 넣는 동작과 OCR의 `.gz` 요청이 불일치했습니다. 언어파일을 명시적으로 `.traineddata`로 준비하고 OCR에서 `gzip:false`를 사용하도록 통일했습니다. 생성된 gzip 캐시 두 종류만 정리하며 원본 언어 패키지나 개인 사진은 삭제하지 않습니다. 수정 후 실제 OCR 브라우저 재시험과 최종 APK 포함 경로·해시 대조 PASS.
