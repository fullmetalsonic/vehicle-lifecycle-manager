# 차량 노트 · 공개 배포 안내

Android 7.0 이상 기기 내 저장형 차량 관리 앱입니다. 로그인 없이 자기 차량을 등록합니다. 개발자의 차량·정비 기록·사진·번호판·차대번호 없이 시작합니다.

## 설치와 사용

1. GitHub Releases에서 APK를 내려받습니다. 설치에 사용한 브라우저/파일 앱에만 Android의 출처 허용을 잠시 부여하고 설치 후 해제할 수 있습니다.
2. 차량 등록에서 이름과 실제 아는 조건을 선택합니다. 모르는 사양은 미확인으로 두세요.
3. 계기판 거리와 과거 정비를 입력합니다. 영수증은 사진 선택 후 기기 내 OCR로 읽고 날짜·거리·항목·금액을 직접 확인한 다음 저장합니다. 자동 확정하지 않습니다.
4. 관리에서 기본/전체 또는 네 묶음을 선택합니다. 장착 부품과 출처 적용조건을 확인하고 거리·기간 주기를 설정합니다. 모든 223항목에 일괄 교환주기를 강제하지 않습니다.
5. 관리 → 알림·백업·기록 도구 → 앱 알림 설정에서 알림을 허용합니다. 1,000 km 또는 30일 이내 일정과 기한 경과를 한국시간 오전 9시대에 안내하도록 예약합니다. 절전 정책에 따라 도착이 늦어질 수 있습니다.

## 기록 보호와 업데이트

기록·사진은 기기에 저장하며 개발자 서버에 보내지 않습니다. 앱 삭제·분실 시 복구하려면 관리의 백업 파일을 별도 보관해야 합니다. 백업은 암호화되지 않으므로 타인에게 공유하거나 공개 저장소에 올리지 마세요. 서버 동기화·계정 복구 기능은 없습니다.

업데이트 확인 시 GitHub에 접속하며 IP 등 통상적인 접속 정보가 GitHub에 전달됩니다. 차량 기록·사진·식별번호를 보내지 않습니다. 관리 → 알림·백업·기록 도구 → 앱 정보·업데이트에서 자동 확인을 끄거나 수동 확인할 수 있습니다. 정식 Release만 비교하며 자동 설치하지 않습니다.

개발용 debug 앱은 정식 앱과 서명이 다를 수 있어 덮어쓰기가 거절됩니다. **기존 앱을 먼저 지우지 마세요.** 검증한 외부 백업을 확보한 뒤 별도 이전 절차가 필요합니다. 기존 정식 앱은 동일 서명 업데이트를 사용합니다.

## 한계

정비 표는 예방 계획 보조자료이지 수명 보증이나 진단이 아닙니다. 실제 사양·제조사 지침·상태와 정비사 판단을 우선하세요. 상태·작업 연동 부품은 고정 교환일이 없을 수 있습니다. 오래된 실측이나 부족한 기록에서는 거리 추정이 제한됩니다.

다양한 실제 영수증 정확도, 제조사별 장기 절전·재부팅 후 오전 9시 알림 도착은 추가 현장 검증 대상입니다. 차량 안전장치나 유일한 정비 알림 수단으로 사용하지 마세요.

## 개발 재현

Node.js, JDK 21, Android SDK 36에서 `npm ci`, `npm run prepare:ocr`, `node scripts/build-mobile.cjs`, `npx cap sync android`를 실행합니다. `android/gradlew -p android assembleDebug`로 개발용 APK를 만듭니다.

정식 빌드는 비공개 키 경로 `VEHICLE_SIGNING_STORE`와 비밀번호 `VEHICLE_SIGNING_PASSWORD`를 실행 환경에 설정한 뒤 `assembleRelease`를 사용합니다. 키 별칭은 `vehicle-note`입니다. 비밀값을 소스·로그·릴리스에 넣지 마세요. 버전은 `android/app/build.gradle`에서 관리합니다.

모델 검사 `node --test ui/*.test.mjs`, 연구 계약 검사 `node tests/research-gate.cjs`. 브라우저 검사에는 Playwright 또는 `VEHICLE_PLAYWRIGHT_PATH`를 사용합니다. [배포 검증](RELEASE_VERIFICATION.md)을 참조하세요.
