# 예방교환 수치 보완

이 문서는 1차 보완 당시의 기록이다. 아래 '남은 조사'와 12개 개수는 당시 상태이며, 현재 결과는 [추가 조사 종결 기록](RESEARCH_COMPLETION.md)과 22개 예방계획 데이터에 반영했다.

2026-09-06. 기존 자료의 '공통 주기 미채택'은 '교환 준비 기준도 제공할 수 없음'이라는 뜻이 아니었다. 이번 보완에서는 **참고 수치와 사용자 선택값**을 별도 데이터로 추가했다. 222개 전 항목의 수치 조사가 끝났다는 뜻은 아니다.

## 표시·계산 규칙

1. `출처 참고범위 / 선택한 예방시점 / 근거 수준 / 적용조건`을 함께 표시한다. 딜러 정비메뉴를 제조사 공식 주기로 표시하지 않는다. 범위의 상단까지 안전하다는 뜻도 아니다.
2. 숫자를 수명, 권고, 설계목표, 업체메뉴, 작업상속으로 구별한다. 실제 고장교환 기록을 예방주기 평균에 섞지 않는다. 이번 자료는 차주 통계로 만든 수명분포가 아니다.
3. 모든 새 기준은 장착확인 후 사용자 선택이다. 선택 전에는 기존 설정을 바꾸지 않는다. 예방상담 시점 경과를 '교환기한 초과'로 표시하지 않는다.
4. 8만→5만처럼 큰 단축은 비용차이를 보여준다. 거리만 기준으로50만km까지6회가10회가 될 수 있다. 아직 정상인 부품을 버리는 비용도 동시정비 절감과 함께 고려한다.
5. 정비회차 맞춤·실제일자·기간 계산은 기존 규칙을 유지한다. 위험증상이나 더 짧은 공식 한계는 준비시점보다 우선한다.

## 아직 수치가 부족한 영역

타이밍체인, 고압연료펌프·인젝터, 터보, EGR·DPF·NOx, 전동워터펌프·통합열관리밸브, 허브베어링은 이번 추가자료만으로 공통 수치를 확정하지 않았다. 접근실패한 SKF/Gates 자료, 연료펌프 내구시험거리, 보증기간을 수명으로 바꾸지 않았다. 이 목록은 `remaining_numeric_research`에 남겨 다음 조사에서 누락되지 않게 했다.

이번 보완은 **12개 예방계획 묶음, 13개 기존 관리항목**을 연결한다. 이 중 8개는 새로 찾은 수치근거, 3개는 관련작업 주기 상속, 1개는 기존 부품번호별 수치의 연결이다. 모든 부품에 예방교환 숫자를 제공했다는 완료 주장은 하지 않는다.
