# 추가 수치 조사 종결 기록

2026-09-06. **공통 관리 데이터 v1과 직전 미결 14개 항목의 추가 자료 검토를 마쳤다.** 전 차종·222종 부품 각각의 수명을 입증했다는 뜻은 아니다. 정비 현장 적용에는 실제 엔진·부품·시장 조건 확인이 필요하다.

## 이번에 달라진 점

## 수치를 기각한 4개 항목도 관리에서 빼지 않는다

- **고압연료펌프:** 구조별 범용 수명표는 채택하지 않았다. Astemo는 자체 무정비 설명과 플랫플런저형의 별도 검사 예외를 함께 제시한다. 관련 구동부·필터 작업, 압력 이상, 금속분·오염을 관리 사건으로 기록한다. 5만km 표면 색 변화는 교환시점이 아니다. [Astemo 원문](https://www.aftermarket.astemo.com/emea/en/news/2026/0717_004925.html)
- **가솔린 인젝터:** GDI 문제 발생 거리와 인젝터 수명을 구별한다. 누설·실화·연료희석·분사 문제가 있으면 해당 진단 기준으로 세척/교환을 결정한다. [Delphi 원문](https://www.delphiautoparts.com/apac/products-and-technologies/gasoline-fuel-systems/fuel-injection-system/petrol-fuel-injection/common-gdi-service-issues)
- **EGR:** 흡기/DPF 작업과 함께 기능 확인할 수 있지만 EGR 자체의 일괄15만km 교환으로 바꾸지 않는다. 카본뿐 아니라 전원·진공·누설 원인도 구별한다. [HELLA 원문](https://www.hella.com/techworld/en/car-parts/auto-electronics/egr-valve/)
- **NOx 센서:** SCR 진단과 전원·통신·오염원 확인, 교환 후 검증에 연결한다. 보증거리나 산업용 센서 운전시간을 승용차 교환거리로 바꾸지 않는다. [HELLA FAQ](https://www.hella.com/techworld/en/car-parts/auto-electronics/nox-sensor/)

이 네 항목에 임의 수명을 만들어 넣는 대신, 사용자가 원하면 기존 **5만km/24개월 종합상담 예약**에 함께 표시한다. 이는 앱 편의 설정이지 부품 제조사의 검사주기가 아니며 증상·공식 검사를 미루지 않는다.

## 비용과 실행 규칙

- 처음에는 자동 적용하지 않는다. 실제 장착과 범위가 맞는 후보를 보여주고 사용자가 선택한다. 위 준비시점의 대부분은 교환 확정이 아니라 예방교환을 결정할 기회다.
- 9.7만→5만, 8만→5만처럼 큰 단축에는 원문 유지 선택과 추가 정비 횟수·비용 경고를 함께 제공한다. 쉽다는 이유로 정상 고가 부품을 과잉 교환하도록 기본 활성화하지 않는다.
- 동시정비는 추가 부품비·추가 공임·기존 부품 잔존가치를 비교한다. 체인과 무관한 워터펌프, 정상 VVT, 모든 센서까지 일괄 묶지 않는다.
- 세척/검사와 교환의 이력을 분리한다. DPF 세척이 본체 교환일을 초기화하지 않는다. 실제 교환일, 실제km, 사용자 선택 정비회차는 따로 저장한다.
- 거리와 기간은 출처가 제시한 축만 사용한다. 거리만 있는 부품에 임의5년을 제조사 수명처럼 추가하지 않는다. 고전압·연료·제동 작업은 전문 정비 절차가 필요하다.

## 완료 범위와 검증

[종결 대장](../data/research-closure.json)은 직전 미결14개 모두에 근거·결정·다음 관리행동을 연결했다. 전체222개 연결표는 **기존 항목의 정책/계획 누락 검사**이며 222개 독립 수명 연구가 아니다. 원문 접근 실패는 성공으로 바꾸지 않았다.

추가 계획 데이터 검사943개 PASS. 기존 수식·연결 검사502,102개 PASS이며 대부분은 거리 내림 전수검사다. 실제 차량 수명 검증·차량별 정비절차 확정·앱 구현·영수증 인식·서버 알림은 이번 조사 완료와 별개다. 새로운 차량 매뉴얼이나 신뢰도 높은 구조별 자료가 생기면 해당 규칙만 재검토한다.
