# 차량관리 적용 기준표 v1.1

2026-09-06. [사전조사 종료 판정](RESEARCH_GATE.md)과 함께 사용한다. 223개 항목: 주기관리29 / 작업·사건연동29 / 측정판정교환140 / 구조별주기25.

이전 v1.0의 근거 부족30개 공통값을 재감사했다. 아래 구조별 항목은 [32개 추가 사례](../data/implementation-rules.json)와 [20개 기존 사례](../data/rule-variants.json)의 적용조건을 확인한다. 숫자를 전 차종의 공식 수명으로 읽지 않는다.

기간/거리 중 먼저 도래하는 시점을 사용한다. 선택형 예방교환은 정상 부품의 추가 교환비용도 설명하고 사용자가 동의해야 활성화한다. 원문이 더 짧으면 원문 기한도 먼저 알린다. 기존 개인설정은 덮어쓰지 않는다.

상태형의 review 간격은 기록과 상태자료를 갱신하는 앱 일정이며 일괄 분해검사나 안전점검 유예기간이 아니다. 실제 교환 판정은 정비보고와 해당 부품의 측정 한계값을 사용한다. 검사·청소·보충으로 교환시계를 리셋하지 않는다.
