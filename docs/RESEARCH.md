# 사전조사 결론

추가 정정: 아래 완료는 공통 관리체계 정리 범위다. 예방교환 수치 보완은 [추가 조사](PREVENTIVE_SUPPLEMENT.md)를 우선하며, 전 항목 수치 조사가 끝난 상태가 아니다. 일반 배터리·쇼바·호스·마운트 등의 선택형 예방기준을 추가했다.

기준일: 2026-09-06. 목표: 25년·500,000 km 동안 기록 누락을 줄이는 범용 개인차량 관리체계. 모델 프리셋 전체 제작 대신 자유입력 차명과 실제 장착계통을 사용한다.

## 1. 조사 종료 기준과 결과

222개 항목 모두를 주기 정책 / 차량·제품별 규칙 / 상태 진단 / 탈거·수리 사건 연동 중 하나로 분류했다. 숫자가 없는 항목을 누락 또는 무교환으로 취급하지 않는다. 고장 가능성이 있다는 이유만으로 모든 부품에 10만 km 수명을 만들어 넣는 방식은 기각했다.

수치 후보 26개는 유지·수정·기각·조건부 적용으로 판정했고, 범용값을 기각한 연료필터·DCT·벨트·냉각수 등은 실제 범위가 확인된 사례를 별도로 제공한다. 222개 각각의 수명을 실증한 것이 아니라, 앱이 어떤 근거로 무엇을 추천하고 무엇을 보류해야 하는지를 정한 것이다.

따라서 **공통 관리체계의 사전조사는 정리 완료**, **전 차종 자동 매칭과 개별 부품 수명 검증은 완료 아님**이다. 후자는 새 차량에 규칙을 적용하는 단계에서 계속 확인할 조건이다. 사용자 차량의 실제 정비표를 이번 자료로 자동 변경하지 않았다.

## 3. 공임과 예방정비

타이밍 **벨트 구동** 워터펌프는 벨트 작업과 묶는 근거가 있다. 타이밍체인 교환에 모든 워터펌프를 자동 추가하면 안 된다. 스트럿 마운트·보호키트, 클러치 탈거 시 내부 CSC, 인젝터 탈거 시 해당 일회용 씰, 변속기 접근 가능한 필터·팬 등은 15개 묶음으로 분리했다.

견적은 `지금 묶을 추가 부품비+추가 공임`과 `나중 독립 작업 예상비`를 비교한다. 실제 견적·남은 사용가치가 없으면 절감액을 만들어내지 않는다. 이미 기한이 지난 정비를 다른 부품과 묶으려고 미루지 않는다. 모든 동반 부품 교환은 상태·절차·사용자 동의를 확인한다.

## 4. 커뮤니티를 반영한 방식

공개 차주 원문에서 보인 냉각수 교환 후 재점검, 등화·액티브 에어플랩 고장, HEV 패드 미교환 경험은 관리항목과 후속 확인 흐름에 반영했다. 서로 다른 차주의 댓글은 한 차량의 이력으로 합치지 않았다. [냉각수 교환 후기](https://damoang.net/car/47144), [HEV 장기 사용 댓글](https://damoang.net/car/75723).

기존 장기주행 포럼 후보 C01–C04와 S38·S50은 원문 접근 실패 또는 불완전 확인이므로 수치 채택에서 제외했다. 커뮤니티만으로 통용 주기·고장 확률을 통계적으로 확정할 충분한 표본은 확보하지 못했다. 이 제한을 숨기지 않고 **커뮤니티에서 통용된다는 표시와 수명 확률 예측을 사용하지 않는 것**으로 결정했다.

## 5. 정밀진단의 역할

계통별 기록 항목은 누유/압력/냉각성능, 연료압·인젝터 리턴량, EGR 명령/작동, DPF 차압·재 축적, 제동 마모치, 하체 유격·감쇠, 충전·배터리 시험, 누수·부식 등이다. 측정 임계값과 작업법은 해당 부품 정비절차에서 가져와야 한다. 오류코드 하나 또는 누적 거리만으로 부품 교환을 확정하지 않는다.

일괄 1만 km 정밀점검을 새로 만들지 않는다. 사용자가 5만 km 또는 24개월 종합상담 알림을 선택할 수는 있지만 이는 **예약 편의 정책이며 공식 점검을 대체하지 않는다**. 공식 안전 점검이나 증상 대응은 별도로 유지한다. 고전압·연료·가스·제동장치 진단과 정비는 적절한 전문 작업자를 전제로 한다.

25년·50만 km는 일정 시뮬레이션 범위이지 이 수명까지 차량 안전을 보증하거나 모든 부품의 교환을 예약한다는 뜻이 아니다.

## 추가 수치 조사 종결

2026-09-06 후속 검토로 예방계획22개·23항목 연결을 확보했다. 직전 미결14개는 수치/사례/작업연동 채택 또는 근거를 남긴 범용수치 기각으로 검토를 마쳤다. [추가 조사 종결 기록](RESEARCH_COMPLETION.md)이 이전 보완 중 상태를 대체한다. 222개 전체 수명입증이나 실차 적용검증은 아니다.
