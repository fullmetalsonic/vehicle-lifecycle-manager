# 차량 노트 0.3.0 · 첫 공개 배포

Android 7.0 이상에서 사용하는 기기 내 저장형 차량 관리 앱입니다. APK를 내려받아 설치한 뒤 자기 차량을 등록하세요. 개발자의 차량·개인 차계부·사진·번호판·차대번호는 포함하지 않습니다.

- 차량·정비 기록·주행거리 관리, 거리·기간 정비 예정, 223개 관리항목과 네 관리묶음
- 기기 내 한국어/영어 영수증 OCR → 사용자가 확인 후 저장
- 백업·복원, 삭제 항목 복구, 선택형 로컬 알림
- 앱 정보에서 수동·자동 업데이트 확인. 자동 다운로드·설치하지 않음

[설치·사용·개인정보 안내](https://github.com/fullmetalsonic/vehicle-lifecycle-manager/blob/main/docs/PUBLIC_RELEASE.md) · [검증 결과와 한계](https://github.com/fullmetalsonic/vehicle-lifecycle-manager/blob/main/docs/RELEASE_VERIFICATION.md)

정비 기준은 관리 보조자료이며 실제 사양·제조사 지침·정비사 판단을 우선합니다. 최초 공개본은 서명·빌드·포함 파일·모델·브라우저 검증을 통과했으나, 이 정식 APK의 실기기 신규 설치와 장기 절전 알림은 미검증입니다. 기기별 문제를 발견하면 개인정보를 가린 뒤 Issues에 알려주세요.

**개발용 앱 사용자는 먼저 삭제하지 마세요.** 정식 APK는 서명이 다를 수 있으므로, 검증된 외부 백업을 확보한 뒤 별도 이전해야 합니다. 백업 파일은 암호화되지 않으므로 공개하지 마세요.
