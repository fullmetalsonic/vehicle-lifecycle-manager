# 차량 노트 0.3.1

- 상단의 불필요한 표시를 제거하고 앱 정보·업데이트를 관리 메뉴로 이동했습니다.
- 홈, 정비 예정, 기록 입력, 이력, 관리 화면의 반복 설명을 줄였습니다.
- 참고 설명과 알림 수신 확인은 펼침 메뉴로 정리했습니다. 삭제·복원·영수증 인식 확인 안내는 유지했습니다.
- 변경 이력과 정비 참고 기준을 읽기 쉬운 항목명·거리·기간으로 표시합니다.
- 체크박스 크기와 펼침 메뉴 표시를 개선했습니다.

정비 계산과 저장 형식은 변경하지 않았습니다. 정식 0.3.0과 같은 서명으로 업데이트할 수 있습니다. 업데이트 전 별도 백업을 권장합니다. 개발용 앱은 서명이 다를 수 있으니 설치가 거절되어도 기존 앱을 삭제하지 마세요.

개인 차량·기록·사진·계정 정보가 없는 배포본입니다. 실기기 설치 검증은 원격 연결 불가로 미실행이며 브라우저 통합 검사와 Android 빌드·서명·내부 자산 검증을 통과했습니다.
